# saferGraph 1.0.0

* open2(): the default value of the pdf_path argument is now the temporary directory of the R session (`base::tempdir(check = FALSE)`) instead of "working.dir" (CRAN policy: no file written outside the temporary directory by default); "working.dir" is still accepted. With pdf = TRUE, the initial graphic parameters are now recovered on a pdf device of the same dimensions that writes no file (`grDevices::pdf(file = NULL)`), whatever the operating system: open2(pdf = TRUE) no longer opens a screen device on Windows and macOS (screen devices are forbidden by R CMD check --as-cran), nor writes a temporary pdf file on Linux.
* post_plot(): with par_reset = TRUE, the default graphic parameters are now recovered on a 7 x 7 inches pdf device that writes no file, instead of a screen device opened by open2(pdf = FALSE), so that post_plot() works without display.
* Backbone v21.1: the invented `x` argument names (absent from the called function signature, for instance `base::any(x = ...)`, `base::all(x = ...)`, `base::sum(x = ...)`, `base::order(x = ...)`) are removed from all the function calls.
* Backbone v21.2: the lib_path argument is now checked whatever the value of safer_check (the `if(safer_check == TRUE){` and `}` lines around the check of lib_path are commented, because lib_path is used outside the safer_check checkings, for instance in the `saferDev::arg_check()` calls): an incorrect lib_path now returns an error even with `safer_check = FALSE`. The documentation of the safer_check argument no longer lists the lib_path check, and the documentation of the lib_path argument no longer says that lib_path is ignored if safer_check is FALSE. `utils::getFromNamespace()` is written with `pos = -1, envir = ` (default value of pos), as required by `saferDev::all_args_here()`.
* Migrated to the safer-r backbone v21.0: every function now follows the saferDev 2.0.0 structure, with arg_check() v2.0.0 semantics (exact class/typeof/mode comparison; class = c("matrix", "array") for matrices, mode = "numeric" preferred for numeric arguments).
* All functions carry the mandatory lib_path, safer_check and error_text reserved arguments.
* Bug fixes found during the migration: mixed-quote paste0() idioms that broke r_debugging_tools argument reporting (post_plot), grDevices::colors() calls applied to par objects instead of applying the par (post_plot custom.par handling), inter_ticks warn_print no longer ignored by the on.exit warning, open2 width/height now reject NA and negative values.
* Complete test suite rewritten in the saferDev style (tests/testthat), including a test-mandatory_args.R replicating the saferDev pattern; code coverage brought to 100% with # nocov markers on OS-specific and internal-error branches.
* All function argument names, local variable names and returned-list component names are now written with underscores instead of dots (e.g. the post_plot() output components $x.mid.left.dev.region etc. become $x_mid_left_dev_region, and the open2() output components $pdf.loc, $ini.par and $zone.ini become $pdf_loc, $ini_par and $zone_ini).
* R (>= 4.5.0) is now required.
